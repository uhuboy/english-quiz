# English Quiz Console Application

โปรแกรมทำแบบทดสอบภาษาอังกฤษ (English Quiz) พัฒนาด้วยภาษา C# โดยระบบจะสุ่มข้อสอบจากคลังข้อสอบ 200 ข้อ และแสดงผลเฉลยทันทีหลังการตอบแต่ละข้อ

## คุณสมบัติหลัก
*   **คลังข้อสอบขนาดใหญ่**: รองรับข้อสอบสูงสุด 200 ข้อผ่านไฟล์ JSON
*   **ระบบสุ่ม**: สุ่มเลือกข้อสอบ 10 ข้อต่อการเล่น 1 ครั้ง
*   **ระบบสลับตัวเลือก**: สลับตำแหน่งตัวเลือก (A, B, C, D) ทุกครั้งที่เล่น
*   **เฉลยทันที**: แสดงผลถูก/ผิด และเฉลยข้อที่ถูกต้องทันทีหลังตอบ
*   **สรุปคะแนน**: สรุปคะแนนรวมเมื่อทำครบ 20 ข้อ

## วิธีการเริ่มต้น

### 1. การเตรียมไฟล์
ตรวจสอบให้แน่ใจว่าไฟล์ `questions.json` อยู่ในโฟลเดอร์เดียวกับโปรแกรม หรือตั้งค่าใน Visual Studio ดังนี้:
- คลิกขวาที่ไฟล์ `questions.json` ใน Solution Explorer
- เลือก **Properties**
- ตั้งค่า **Copy to Output Directory** เป็น **Copy if newer**

### 2. โครงสร้างไฟล์ JSON
ข้อมูลข้อสอบต้องอยู่ในรูปแบบ JSON ดังนี้:
```json
[
  {
    "Text": "She ____ to school every day.",
    "Options": ["go", "goes", "going", "gone"],
    "CorrectIndex": 1
  }
]
```
*(หมายเหตุ: `CorrectIndex` เริ่มนับจาก 0 โดย 0 คือตัวเลือกแรก)*

### 3. การรันโปรแกรม
1. เปิดโปรเจกต์ด้วย Visual Studio หรือ .NET CLI
2. รันโปรแกรมผ่าน `F5` หรือใช้คำสั่ง `dotnet run`
3. พิมพ์คำตอบ (A, B, C หรือ D) แล้วกด Enter เพื่อทำข้อสอบ

## ข้อมูลทางเทคนิค
*   **Language**: C#
*   **Framework**: .NET (รองรับ .NET Core, .NET 5/6/7/8+)
*   **Library**: `System.Text.Json` สำหรับจัดการข้อมูลข้อสอบ
